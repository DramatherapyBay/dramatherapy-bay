治療取向

甚麼是 戲劇治療？

戲劇治療是一種心理治療方式，透過創意、想像、遊戲及多元表達媒介，協助我們認識自己、理解自身經歷，以及探索內在的感受與需要。

雖然稱為「戲劇治療」，但你並不需要懂得演戲、喜歡表演，或具備任何藝術方面的技巧。治療過程中亦沒有任何表演要求，你不需要在任何人面前演出，也不需要創作出符合特定標準的作品。

戲劇治療的核心，是透過不同方式探索生活中正在發生的事情、我們的感受，以及我們如何看待自己和與他人相處。

有時候，要透過言語談論自己的經歷並不容易。我們可能難以找到合適的詞語表達感受，被強烈的情緒淹沒，或不斷重複相同的思考模式，卻未能真正理解背後的原因。

戲劇治療提供了另一種探索這些經歷的途徑。透過想像、意象、物件、故事及創意活動，我們可以逐漸表達那些單靠對話未必容易傳達的感受與經歷，並從中發展新的理解與觀點。

以整體為本的 治療方式

戲劇治療不單著重思想與言語表達，亦重視身體經驗、情緒、想像力及個人的內在世界，讓人在治療過程中有機會從不同層面認識自己，探索內在經歷，並發掘新的理解與可能性。

透過創意活動、遊戲及故事探索等方式，參與者可以在具支持性的治療關係中，以自己的步伐接觸及探索較為困難的情緒、生命經歷與人際關係，逐步提升自我覺察。

這種治療方式運用多元創意技巧，例如角色扮演、即興創作、故事敘述及創意身體活動，讓參與者在治療師的引導及陪伴下，以適合自己的方式探索內在經驗。

整個治療過程由具備專業資格及註冊認可的治療師帶領，並透過協作、尊重及接納，建立一個安全且具支持性的治療空間。

專業實踐與研究基礎

戲劇治療是一門受專業規管的心理治療專業。在英國，戲劇治療師須向健康與護理專業委員會（Health and Care Professions Council，HCPC）註冊，方可使用受規管的專業職銜。戲劇治療廣泛應用於不同服務環境，包括醫院、學校、社區服務及私人執業，並因應不同群體的需要而發展出多元化的治療實踐。

常見的 治療技巧

戲劇治療會因應個人的需要、治療目標及當下的狀態，靈活運用不同創意媒介。以下是一些常見的探索方式：

角色扮演

透過探索不同角色及處境，從多角度理解自己與他人的經歷，並嘗試以不同方式回應生活中的情況。

故事敘述

透過創作、重述及探索故事，梳理個人經歷、情緒及生命中的意義。

身體動作與表達

運用身體動作及非言語表達，探索身體感受、情緒與自我覺察之間的連結。

創意寫作

透過文字、書寫及內心對話，整理和表達思想與感受，讓較難理解的內在經驗得以呈現及探索。

沙盤及繪畫

運用沙盤、圖像及象徵性創作，呈現內在世界、感受及難以言喻的經歷。

隱喻與即興創作

透過象徵、想像及即興探索，發掘新的觀點，培養彈性思考及對自身經驗的理解。

誰適合接受戲劇治療？

戲劇治療可支援不同年齡及背景的人士，特別是正在面對情緒、心理、人際關係或生活轉變等挑戰的人。治療方向及介入方式會因應每個人的需要、能力及個別情況而調整。

✓ 成癮復康及戒癮支援
✓ 焦慮及抑鬱情緒
✓ 專注力不足／過度活躍症（ADHD）及自閉症譜系相關需要
✓ 喪親、失落及哀傷歷程
✓ 認知功能障礙及失智症支援
✓ 溝通及表達方面的困難
✓ 飲食困難及飲食失調
✓ 學習障礙及相關支援需要
✓ 人生轉變及適應困難
✓ 人格障礙及相關情緒與人際關係困難
✓ 創傷經歷及創傷後壓力症（PTSD）

專業認可與規管

戲劇治療在不同國家及地區均有其專業發展及認可制度。在英國，戲劇治療師受健康與護理專業委員會（HCPC）規管，並有英國戲劇治療師協會（BADth）等專業組織支持業界發展及專業實踐。在北美，北美戲劇治療協會（NADTA）亦致力推動戲劇治療的專業發展、教育及研究。
